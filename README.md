# AI Privacy Gateway

## Milestone 1

This project will create a privacy gateway for an academic advisor using AI to summarize advising meetings.

The AI-assisted task is to convert rough advising notes into a concise summary and action list for students while keeping sensitive student information local.

## Current Status

Milestone 1 focuses on requirements and design. The full privacy gateway has not been implemented yet.

A small Java Tech Spike was created to confirm that the Java runtime and basic text input/output work.

## Runtime

OpenJDK 24.0.2

## Compile Command

javac TechSpike.java

## Run Command

java TechSpike

## Example Input

Meeting notes for John Doe

## Example Output

You entered: Meeting notes for John Doe
