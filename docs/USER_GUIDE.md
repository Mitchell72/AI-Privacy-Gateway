# User Guide

## Milestone 1

The complete AI Privacy Gateway has not been implemented yet. Milestone 1 contains a small Tech Spike used to verify Java input and output.

## Requirements

OpenJDK 24.0.2

## Compile

From the src directory:

javac TechSpike.java

## Run

java TechSpike

The program will ask the user to enter text and then print the entered text back to the terminal.

## Example

Input:

Meeting notes for John Doe

Output:

You entered: Meeting notes for John Doe
